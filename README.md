# sms-spam-classification

## Постановка задачи

Цель проекта — разработка модели классификации SMS-сообщений на спам и не спам. Такая классификация необходима для фильтрации нежелательных сообщений и защиты пользователей от мошенничества, рекламного и фишингового спама.

## Формат входных и выходных данных

**Входные данные**: текстовые SMS-сообщения.  
**Пример**:  
“Go until jurong point, crazy.. Available only in bugis n great world la e buffet... Cine there got amore wat...”

**Выходные данные**: бинарный класс (0 — не спам, 1 — спам) и вероятность принадлежности к классу спам.  
**Пример**: 0 (не спам) с вероятностью 99.8%.

## Метрики

- **Accuracy** — доля правильно классифицированных сообщений. Учитывает общую точность, но может быть завышена из-за дисбаланса классов (~13% спам).
- **F1-score** (на классе спам) — основная метрика, гармоническое среднее precision и recall. Лучше отражает качество на редком классе.

## Валидация и тест

Данные делятся на тренировочную, валидационную и тестовую выборки в стратифицированном режиме (сохранение пропорций классов) и фиксированным `random_state` для воспроизводимости.

## Датасет

- **Источник**: [SMS Spam Collection (UCI Machine Learning Repository)](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset/data?select=spam.csv)
- **Размер**: 5572 сообщения
- **Классы**: ham (не спам) ~86.6%, spam ~13.4%

## Особенности и возможные проблемы

- Сильный дисбаланс классов → требуется взвешивание функции потерь (`pos_weight`).
- Короткие тексты с разговорным стилем, сокращениями, опечатками.

## Модель

Двунаправленная LSTM с улучшениями:

- Embedding-слой
- Bidirectional LSTM (3 слоя, hidden_dim=512)
- Mean pooling по последовательности с маской (учитывает padding)
- Взвешенный BCE-loss для борьбы с дисбалансом
- EarlyStopping по val_f1

## Technical Details

### Setup

1. **Клонирование репозитория**
```bash
   git clone <repo_url>
   cd sms-spam-classification
```
2. **Установка uv (если ещё не установлен)**

Следуйте инструкциям на https://docs.astral.sh/uv/getting-started/installation/

3. **Установка зависимостей**
```bash
uv sync
```
4. **Установка pre-commit хуков**
```bash
uv run pre-commit install
```
5. **Проверка качества кода**
```bash
uv run pre-commit run -a
```
6. **Базовый запуск обучения (использует значения из конфига)**
```bash
uv run -m spam_classifier.commands train
```
7. **Обучение с переопределением параметров (используйте __ вместо . в именах параметров)**
```bash
uv run -m spam_classifier.commands train trainer__max_epochs=3
```
8. **Просмотр результатов**

Запустите MLflow UI:
```bash
mlflow ui
```

Откройте в браузере: http://127.0.0.1:8080

Там вы увидите:

• Все эксперименты в sms-spam-lstm

• Логированные гиперпараметры, метрики (loss, val_f1, test_f1 и др.)

• Git commit

• Лучшую модель как артефакт

9. **Скачивание данных (если нужно)**
```bash
uv run -m spam_classifier.commands download
```

Данные будут автоматически получены через DVC или скачаны с открытого источника при первом запуске обучения.
